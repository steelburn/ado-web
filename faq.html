FAQ

Questions, answered.

The things people ask before installing.

Is ADO Code free?

Yes. ADO Code itself is free — you bring your own Azure DevOps access and your own LLM API key (OpenAI-compatible, OpenRouter, Ollama, LM Studio or Anthropic).

Does it work with Azure DevOps Server (on-premises)?

Yes. Point the connection at your Azure DevOps Services organisation or your Azure DevOps Server collection URL, and authenticate with a personal access token.

How do coding agents run — do they touch my working tree?

Delegated tasks run in an isolated git worktree on a separate branch. You review the diff and merge it yourself.

Which LLM providers are supported?

Any OpenAI-compatible API — including OpenRouter, Ollama and LM Studio — plus the Anthropic API. Model and reasoning effort can be set per mode.

What are the four modes?

Chat answers questions, Plan inspects read-only, Act performs agentic work with approvals, and YOLO runs fully autonomously.

Is my code sent anywhere?

Requests go only to the LLM provider you configure with your own key. ADO Code ships no analytics or telemetry of its own.
